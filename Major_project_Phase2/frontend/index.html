Project Details & Model Performance

Project Overview

This system predicts stock price direction using a fusion of NLP sentiment analysis on corporate earnings calls and deep learning models trained on 10+ years of historical financial data. The fusion formula combines sentiment probability (40%) with deep learning prediction (60%) for optimal accuracy.
